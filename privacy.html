Privacy policy

UDPA UMGE Audience Intelligence · Last updated 8 November 2026

Purpose and operator

This personal application is operated by the owner of Whispers of Battle and The Third Derivative to analyze their own YouTube channels and improve documentary production. Questions and deletion requests can be sent to babuiparia@gmail.com.

Google data accessed

With the owner's consent, the application requests read-only YouTube account access and read-only YouTube Analytics access. Data may include channel and video identifiers, titles, publication dates, durations, views, watch time, average viewing duration, average percentage viewed, engagement and subscriber changes, traffic-source categories and audience-retention curves, when the authorized APIs support them.

The application does not request permission to upload, edit or delete videos. The analytics integration does not request individual viewers' email addresses or private viewer identities.

How data is used

Reports are used to produce owner-requested summaries, compare videos and align audience-retention observations with production records. AI-assisted tools may help interpret these reports for the owner. Such observations are not treated as proof that a production technique caused a change in viewing behavior.

The application does not sell Google data, use it for advertising or unrelated profiling, or build a generalized model-training dataset from it.

Storage and service providers

OAuth client credentials and refresh tokens are held in GitHub Actions secrets. Authorized collection runs use short-lived access tokens without intentionally writing them to source files or reports.

Analytics snapshots, verification results and production records may be stored in private repositories, workflow artifacts, databases and private working files. Google provides the source APIs; GitHub provides repository, workflow and secret storage. OpenAI/ChatGPT and hosting infrastructure may process reports and production records when the owner asks for analysis or production work. Access is limited to the owner, authorized collaborators and the service processing requested work.

This public information site publishes no private analytics or credentials. GitHub, as the website host, may process ordinary request metadata under its own privacy notice. The site includes no application analytics trackers or advertising scripts.

Retention and deletion

Temporary connection-check artifacts are configured to expire after 30 days. Private repository records, database snapshots and production files can persist until the owner removes them; automatic retention cleanup is not yet implemented. Version history and backups may retain older copies and require separate cleanup.

The owner can request deletion using the contact address above. Deletion should cover the applicable active reports and credentials, with repository history and retained backups handled separately. Revoking Google access stops future authorized collection; it does not automatically remove reports already stored.

Control and revocation

The owner can revoke access through Google Account third-party access settings, remove the GitHub Actions secrets and disable collection workflows. No public signup or third-party channel onboarding is offered.

Google and YouTube policies

Google API data is used for the channel owner's requested analytics and production workflow. The operator is responsible for maintaining practices consistent with the Google API Services User Data Policy and applicable YouTube API Services Developer Policies.

Changes

This notice will be updated as deployed data practices change. Expanded access requires the owner's authorization.
